# M4 · Output

**Owner:** Saikirantejas GS (1464)

## What it does
Stores cleaned and scored records in SQLite, exports the JSON files the website reads (`stations.json`, `records/<station>.json`, `summary.json`, `alerts.json`, Reliability Lab scenarios), applies alert rules, and generates PDF quality reports with OpenPDF.

## Why
This is how people use the results: the map, the alerts and a report a reviewer can hold in their hand.

## Status
Package created in Phase 1. Implementation: Phase 4 (weeks 7–8).
